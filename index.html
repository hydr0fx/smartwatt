2. Smart Life / Tuya Cloud API

Deine Steckdosen laufen in Smart Life über die globale Tuya-Plattform. Über die kostenlose Tuya Developer Cloud können wir alle Live-Werte (Watt, Volt, Ampere, On/Off) abgreifen, während du die Steckdosen weiterhin ganz normal in Smart Life bedienen kannst!

📖 Kurzanleitung: Woher bekomme ich meine Tuya API-Schlüssel? (Dauert 3 Minuten)

1. Gehe auf iot.tuya.com und erstelle ein kostenloses Entwickler-Konto.

2. Klicke links auf Cloud -> Development -> Create Cloud Project (Region: Central Europe).

3. Klicke im Projekt auf den Reiter Devices -> Link Tuya App Account und scanne den angezeigten QR-Code mit deiner Smart Life App (im Profil unter "QR-Code scannen").

4. Unter Project Overview findest du deine Access ID und dein Access Secret. Trage sie oben ein und klicke auf "Verbindung testen"!
