Smart Life / Tuya Verbindung

Verknüpfe deine echten smarten Steckdosen

Tuya / Smart Life Cloud API

Deine Steckdosen laufen in Smart Life über das weltweite Tuya-Ökosystem. Über die offizielle kostenlose Tuya Developer API greift SmartWatt alle Live-Werte (Watt, Volt, Ampere, On/Off) ab – während du die Steckdosen weiterhin ganz normal in Smart Life bedienst!

📖 3-Minuten-Anleitung: Woher bekomme ich meine Tuya API-Schlüssel?

1. Gehe auf iot.tuya.com und erstelle einen kostenlosen Entwickler-Account.

2. Klicke links auf Cloud -> Development -> Create Cloud Project (Region: Central Europe).

3. Klicke im Projekt auf Devices -> Link Tuya App Account und scanne den QR-Code mit deiner Smart Life App.

4. Unter Project Overview findest du deine Access ID und dein Access Secret. Trage sie oben ein und klicke auf "Verbindung testen"!
